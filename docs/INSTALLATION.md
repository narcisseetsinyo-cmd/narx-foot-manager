# Installer NARX Foot Manager 3.11.0

Toutes les applications partagent les mêmes données que le site **https://narx-foot-manager.web.app/app/** (mises à jour en direct ; les dernières données consultées restent lisibles sans connexion).

| Appareil | Fichier / méthode | Installation |
|---|---|---|
| **Windows** 10 et 11 | `NARX-Foot-Manager-Setup-3.11.0.exe` | Double-cliquez. Si « Windows a protégé votre ordinateur » : **Informations complémentaires → Exécuter quand même**. |
| **Mac Intel** | `NARX-Foot-Manager-3.11.0-mac-x64.dmg` | Ouvrez le .dmg, glissez l'icône dans **Applications**. Premier lancement : **clic droit → Ouvrir → Ouvrir** (ou Réglages Système → Confidentialité et sécurité → **Ouvrir quand même**). |
| **Mac puce Apple** (M1 à M4) | `NARX-Foot-Manager-3.11.0-mac-arm64.dmg` | Comme ci-dessus. |
| **Android** | `NARX-Foot-Manager.apk` | Ouvrez le fichier sur le téléphone → **Paramètres → Autoriser cette source** → Installer. Sans le fichier : ouvrez l'adresse dans **Chrome** → menu **⋮** → **Installer l'application**. |
| **iPhone / iPad** | Safari, aucun fichier | Ouvrez https://narx-foot-manager.web.app/app/ dans **Safari** → **Partager** → **Sur l'écran d'accueil** → Ajouter. |

## Administration et dirigeants

- L'administration s'ouvre sur n'importe quel appareil avec le mot de passe administrateur (bouton **Dirigeant de club · Accès admin** en haut).
- Chaque téléphone ou ordinateur reçoit automatiquement un accès dirigeant personnel.

## Anciennes données de l'ordinateur (Windows / Mac)

Les données enregistrées sur l'ordinateur par les versions 3.10 et précédentes restent disponibles : menu **Fichier → Données de cet ordinateur (hors connexion)**. Pour les envoyer dans les données partagées : dans ce mode, **Admin → Exporter une sauvegarde** ; puis **Fichier → Données partagées (en ligne)**, déverrouillez l'administration et **Admin → Restaurer une sauvegarde**.
